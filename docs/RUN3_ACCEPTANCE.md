# Run 3 acceptance gates

Run 3 is not complete until all of the following are demonstrated on the same current branch head:

- 53-joint source-grounded finger rig drives a real rifle grip pose.
- Right-hand trigger/grip contact and left-hand support contact are measured against weapon sockets/surfaces.
- Finger skin weights remain normalized and bounded to four influences.
- Shoulder, elbow and wrist deformation has technical and visual evidence under the rifle pose.
- Armor components remain separate semantic state and do not visibly clip the posed body/undersuit.
- Godot import/render evidence exists for neutral vs posed character under the same evidence lighting.
- Failed pose/corrective attempts remain recorded rather than silently overwritten.
- No high-end/production claim is made unless the actual in-engine result survives close inspection.
