# Kettlejack visual rehearsal

This lane exists because structural validity was not enough.

The first Kettlejack package proved real geometry, materials, skinning, skeleton state, animation tracks and Godot import. A software-rendered contact sheet then exposed an obvious visual gap: the body still read as a generic human substrate with primitive attachments rather than the generated Kettlejack design target.

The v0.2 rehearsal therefore treats rendered pixels as evidence and repairs only visible, attributable gaps while preserving the existing structural truth boundary.

Target repairs:

- larger, more readable stylized head and shorter arm span;
- actual cartoon eye geometry and pupils;
- visible hair mass rather than a bare scalp;
- goggles moved to the forehead instead of replacing the eyes;
- fuller scarf, belt pouches and workshop silhouette cues;
- enlarged kettle backpack with frame, gauge, vent and exhaust;
- mechanical right lower leg that visually covers the human substrate;
- work boot geometry that covers the left source foot;
- a wrench head that reads as an open-jaw wrench rather than a pole/fork;
- automatic Godot review renders for static and animation poses.

## Review views

The dedicated proof workflow must render and retain:

- front;
- three-quarter;
- side;
- back;
- idle;
- run;
- jump;
- wrench swing;
- victory.

These images are evidence, not automatic aesthetic approval. The machine may prove that it rendered a particular asset/clip/camera; a human or visual observer still judges whether the result is visually good.

## Truth boundary

A passing v0.2 build may claim real 3D geometry, multi-material skinning, a 23-joint skeleton, named animation clips, Godot import and exact render captures. It may not claim pixel-faithful reconstruction of the concept, production deformation quality, facial animation, cloth simulation, gameplay-controller behavior, performance readiness, final art acceptance, release status or CANON.
